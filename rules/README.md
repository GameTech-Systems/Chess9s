# rules/

- `parameters.json`: the registry of every rule variable, with defaults and options.
- `rulesets/`: named, versioned bundles of overrides. `draft-2p.json` is the working 2-player draft.
- `schema/`: JSON Schemas that validate both.

All values are currently **seed data and unverified**. They come from an early plan and will be confirmed through the process in [docs/GOVERNANCE.md](../docs/GOVERNANCE.md). See [docs/RULES-FRAMEWORK.md](../docs/RULES-FRAMEWORK.md) for how it works.
