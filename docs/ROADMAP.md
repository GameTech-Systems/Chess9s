# Roadmap

Phases end with exit criteria, not dates. Later phases wait for earlier ones to be stable.

**Phase 0: Foundation.** Licensing, governance, templates, rules framework, and project memory for AI-assisted development. *Exit:* a public repo that a contributor, or Claude Code, can start from cleanly.

**Phase 1: Engine and board.** Workspace scaffold, rules loader, board with every special square, piece movement one piece at a time, then check and checkmate. *Exit:* the test suite passes and a 2-player hot-seat game runs in the browser with legal-move highlighting.

**Phase 2: Playable product.** Rule picker with status badges, quality-of-life features (legal-move toggle, last-move highlight, undo, danger indicator, sound, rules screen, timer), a computer opponent, guest play, and a mobile-friendly layout. A simulation harness checks the default 2-player ruleset for fairness, and the checked default is published as a Candidate with its evidence. *Exit:* a full game against the computer on a phone browser, and a fairness-checked default 2-player ruleset.

**Phase 3: Public launch on chess9s.com.** Deployment, privacy policy, open Discussions, and a "Suggest a variant" link. *Exit:* outside testers have finished games and sent feedback.

**Phase 4: Official tournament rules.** A public discussion period on the Candidate ruleset, ratification, and a tournament rules page. *Exit:* an immutable Official 2-player ruleset.

**Phase 5: Online multiplayer.** Room codes, guest play, reconnection, and a ruleset locked per game.

**Phase 6: 3-player Dragon mode (experimental).** Dragon role, exit rules, timer, win conditions, and balance simulations across variants.

**Phase 7: Growth.** Mobile apps, accounts and stats, and tournaments.
